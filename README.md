# push_swap

## Description

`push_swap` sorts integers using two stacks and a limited set of allowed operations.

The challenge is not only to produce a correct sort, but also to minimize the number of instructions. The project focuses on algorithm design, stack manipulation, input validation, and performance optimization.

## Instructions

Compile the project:

```sh
make
```

Run it with a list of integers:

```sh
./push_swap 4 2 1 3
```

The program prints the operations needed to sort stack `a`.
